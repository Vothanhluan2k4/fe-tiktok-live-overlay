# fe-tiktok-live-overlay

TikTok Live Comment/Gift TTS Reader - React + Vite Streamer Dashboard & OBS Overlay Widget

## System Features
- Streamer Dashboard for TikTok username input, voice settings, and live event testing
- Transparent OBS Browser Source Overlay Widget (`/overlay/:token`)
- Smart Audio Queue Engine preventing overlapping speech audio
- Live event cards with confetti gift effects

## Setup & Run
```bash
npm install
npm run dev
```
